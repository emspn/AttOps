# AttOps - Modern Field Workforce Management

AttOps is a comprehensive solution designed for organizations to manage attendance, tasks, and field operations in real-time.

---

## 📥 Download & Install

For the best experience, download the latest version directly to your Android device.

[<img src="https://img.shields.io/badge/Download-Latest%20APK-brightgreen?style=for-the-badge&logo=android" width="250">](https://github.com/emspn/AttOps/releases/latest/download/app-release.apk)

### 🚀 How to Install
1. **Download the APK** by clicking the button above on your Android phone.
2. **Open the file** once the download is complete.
3. If prompted, allow **"Install from Unknown Sources"** in your phone settings.
4. Tap **Install** and launch AttOps!

---

## ✨ Key Features

*   **📍 Precision Attendance:** Geofenced check-ins with photo verification.
*   **📋 Task Management:** Assign, track, and manage field tasks with real-time updates.
*   **👥 Staff Directory:** Manage employee profiles and organizational structure.
*   **📊 Real-time Reports:** Instant visibility into workforce productivity (Admin/Owner only).
*   **🔔 Smart Notifications:** Stay updated with task assignments and approvals via Firebase Cloud Messaging.

---

## 🛠 For Organization Admins

### Setting up your Organization
1. Sign in using your **Google Account**.
2. Create your Organization profile.
3. Share the **Organization Code** with your employees.
4. Add employees via the **Staff** tab to provide them with login credentials.

## 🔒 Security & Privacy
AttOps uses enterprise-grade security via **Supabase Auth** and **PostgreSQL RLS** (Row Level Security) to ensure your organization's data is only accessible to authorized personnel.
